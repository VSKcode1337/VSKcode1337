<product_requirements>
The goal is to build a PCS High-Win Sniper + Auto-TP, a high-frequency trading bot for the BNB Smart Chain. The application must automatically detect new token listings on PancakeSwap, execute trades within seconds, and manage positions with predefined rules.

**Core Features:**
1.  **Real-Time Sniping:** Subscribe to PancakeSwap's  and  events via WebSocket to detect new liquidity pools instantly.
2.  **Automated Trading Logic:** Implement a two-stage buy process (probe buy + full buy) to avoid honeypot scams.
3.  **Risk Management:** Integrate comprehensive risk filters, including minimum liquidity, token tax limits, ownership checks, and holder concentration analysis.
4.  **Position Management:** Automatically execute take-profits at user-defined multipliers (e.g., 10x, 20x, 30x) and apply stop-loss or time-based exits.
5.  **User Interface (UI):** A professional and mobile-responsive web dashboard allowing users to:
    *   Start and stop the sniper bot.
    *   Manage multiple trading wallets securely.
    *   Configure API keys (QuickNode, BSCScan) and trading parameters (trade size, risk levels).
    *   Monitor live performance, including open positions, realized/unrealized P&L, and a feed of newly detected pairs.
6.  **Demo Mode:** A safe testing environment with dedicated demo wallets and simulated funds to allow users to test strategies without financial risk.
</product_requirements>
